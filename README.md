# Web-kehittämisen perusteiden harjoitustyö
* Aiheeksi valikoitui: Pelikahvila, jonka nimeksi annettu @Belejä
* Sivuston alustava rakenne:
    - index.html tulee sisältämään kahvilan etusivun, josta löytää kahvilan esittelyn
    - pelit.html tulee sisältämään kahvilan pelikokoelmaa ja pelien vuokraushinnastoa
    - tuotteet.html tulee sisältämään kahvilan tuotteita ja niiden hinnastoa
    - yhteystiedot.html tulee sisältämään kahvilan yhteystiedot ja yhteydenottolomakkeen
